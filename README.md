# Coffee Chat Networking Skill

A Claude Code skill for preparing and executing effective networking coffee chats — from identifying targets to following up.

## What It Does

This skill guides you through a 5-step coffee chat workflow:

1. **IDENTIFY** — Find the right people to talk to (warm intros, alumni, hiring managers, professors)
2. **RESEARCH** — Deep-dive on the person + their industry (company news, business model, competitive landscape)
3. **OUTREACH** — Craft personalized messages (LinkedIn, email, WeChat templates)
4. **PREPARE** — Build question lists and conversation flows tailored to the person type
5. **DEBRIEF & FOLLOW-UP** — Structured review (supports audio transcript upload), thank-you messages, and long-term relationship maintenance

## Who It's For

University students preparing for:
- Informational interviews
- Career fair follow-ups
- Networking with alumni, professors, or industry professionals
- Job/internship seeking through relationship building

## Install

Copy `skill.md` into your Claude Code skills directory:

```bash
# Clone the repo
git clone https://github.com/Bill306/coffee-chat-skills.git

# Copy to your skills directory
mkdir -p ~/.claude/skills/coffee-chat
cp coffee-chat-skills/skill.md ~/.claude/skills/coffee-chat/skill.md
```

## Usage

In Claude Code, trigger the skill with keywords like:
- "coffee chat"
- "networking"
- "informational interview"
- "reach out to someone"
- "follow up after chat"
- "career fair"

## Language

The skill is bilingual (English + Chinese), designed for students comfortable with both languages.
